Step A: Styling Approach

CSS Custom Properties
→
:root in app/globals.css

Tokens live as CSS custom properties on :root for light mode and [data-theme='dark'] for dark mode. Components reference them via var(--paper), var(--ink), etc. No build step — every colour, radius, and shadow rebrand by changing one variable. Fonts are supplied by next/font as CSS variables --font-display, --font-mono, --font-body.

Typography Rules

Line Height: 1.5 for body text, 1.3 for headings, 1.0 for large numbers (deadline countdown)
Letter Spacing: -0.01em for display headings, -0.03em for large titles, 0.04–0.08em uppercase for labels/badges
Font Weight: 600 for headings and emphasis, 400 for body, 500 for mono figures
Text Transform: Uppercase for status pills, badges, table headers, section labels. Sentence case for everything else.

Step F: Responsive Plan

Where the layout changes, and to what.

BreakpointLayout Change
Below 640px (phone) Nav stacks vertically and centers. Masthead becomes column layout. Nav links wrap to 2 rows with touch-sized padding (10px 12px). Heading shrinks from 28px to 24px.
Below 480px (small phone) Cards padding reduces from 28px to 20px. Auth actions go single-column. Route.best margins shrink. Bottom padding reduces. Category bar labels get tighter min-width.
640–900px (tablet) Dashboard 2-column grid collapses to single column. Calc grid continues auto-fill.
Above 900px (desktop) Dashboard uses 2-column grid (1.2fr / 1fr). Full nav bar horizontal. Cards sit 3+ across via grid.
Hard Requirement
No horizontal scrolling on a 375px-wide phone (iPhone SE). All grids use auto-fill/minmax and overflow-x: hidden on the container.

Design Principles

Ledger-Minimalist
Clean paper aesthetic with glass cards. No decorative colour — green is reserved for active states and money-saved moments.
One Input, All Outputs
Single Income Profile drives every computation. Tax results, advisor recommendations, and walkthroughs all recalculate live from the same inputs.
Citation-Backed
Every recommendation cites the exact regulation it stands on (NIRC sections, TRAIN, CREATE, RA 9178) in plain language.
